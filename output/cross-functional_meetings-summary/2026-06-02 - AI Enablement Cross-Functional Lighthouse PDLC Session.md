## Meeting Title
AI Enablement: Cross-Functional Lighthouse PDLC Session — June 2, 2026

## Short Description
Presentation of a structured AI tool selection framework mapping six AI tools to five usage lanes. The session provided practical guidance on when to use each tool, their integration capabilities, limits, and a routing matrix to help teams choose the right tool for each use case.

## Key Points / Topics
- **Six AI tools** covered in the framework:
  1. Robo (Atlassian AI) — Jira/Confluence knowledge and search
  2. Microsoft Copilot — productivity, collaboration, document generation
  3. ChatGPT Agents — cross-tool reasoning and multi-step automation
  4. Cursor — AI-assisted coding in the IDE
  5. GitHub Copilot — inline code suggestions and PR assistance
  6. CodeMie — SDLC orchestration and multi-repo agent workflows
- **Five usage lanes** and their primary tool mapping:
  1. Knowledge discovery → Robo
  2. Productivity and collaboration → Microsoft Copilot
  3. Cross-tool reasoning and automation → ChatGPT Agents
  4. Developer coding assistance → Cursor / GitHub Copilot
  5. SDLC orchestration → CodeMie
- **Integration comparison**: each tool assessed for its ability to connect with Jira, Confluence, GitHub, Teams, and SharePoint
- **Limits per tool**: context window sizes, rate limits, file size caps, available connectors, and permission models discussed
- **Use case routing matrix**: decision guide helping teams answer "which tool should I use for this?" based on the nature of the task
- **Claude Code** mentioned as an emerging addition to the developer lane — evaluation in progress, not yet in the official framework
- Discussion of overlap zones where multiple tools could apply — guidance on default choices and when to combine tools
- Framework intended as a living document; teams encouraged to contribute new use cases and routing examples
